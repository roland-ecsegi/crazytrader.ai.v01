# Pre-T012 adversarial architecture/security pass

This is a separate autonomous architecture review pass before Hard Risk
implementation. It reviews the repository interfaces and proposed Phase 4 design;
it is not human approval, a separate-model review or certification evidence.

## Reviewed boundary
AGENTS invariants; Phase 4 ExecPlan; TRADE_INTENT/RISK_SECURITY/certification specs;
Phase 2 market state/manifest/checkpoint; Phase 3 ledger/portfolio/fill/source state;
RiskDecision/PolicyDecision V1; adopted OPA version/interface.

## Findings and required controls

1. **Critical: caller risk_effect is not truth.** A BUY labeled reducing or SELL
   larger than attributable holdings must deny. Classifier must independently
   derive Spot direction, account for pending/unresolved orders and bind to exact
   intent/state. Unknown REBALANCE is not neutral permission.
2. **Critical: healthy flags/caps cannot be agent input authority.** Production
   context adapter must load canonical internal portfolio/market/config/provenance;
   reject stale/hash mismatch/unknown cost/P&L. Fixture context is explicitly a test
   surface, never an agent execution tool.
3. **Critical: bare ALLOW replay/TOCTOU.** Existing RiskDecision/PolicyDecision lack
   execution expiry/state hash. Add bound authorization evidence and immutable
   audit before future execution, which must recheck expiry, state, filters and
   duplicate intent/request identity immediately before venue mutation.
4. **Critical: degraded global kill can trap capital or permit shorts.** Explicit
   cancel-only versus owner-approved flatten/reduction policy, current ownership,
   no-short quantity proof and known venue state are required. Stale price must not
   block an otherwise provable exact-quantity protective SELL; unprovable notional
   conversion must deny. AI/OPA-network outage cannot improvise new authority.
5. **High: Low/Medium/High must never loosen owner/system limits.** Compute effective
   minima independently and version all configs; reject missing/changed profile,
   excessive daily loss/drawdown, frequency/concentration/liquidity/spread/slippage.
6. **High: arithmetic/sizing ambiguity.** Full Decimal context, conservative explicit
   tick/step rounding and exactly-one authoritative sizing input; no binary float
   or ambient precision. Missing price/filter provenance denies increasing risk.
7. **High: unknown third-asset fees.** Ledger honestly reports unknown quoted P&L
   until sourced conversion. Risk adapter must not convert null to zero or assume
   drawdown/loss healthy. Bounded reduction remains possible with inventory proof.
8. **High: OPA response/bundle substitution.** Verify exact policy bundle hash,
   decision shape/version/identity, bounded timeout; down/malformed/unknown denies
   increasing risk. A separate versioned local protective policy must be explicitly
   owner authorized; no broad agent boolean bypass.
9. **Material later blocker: L5/L6 circular live wording.** AGENTS invariant10 forbids
   real money before L6, while L6 requires actual L5 canary trades. Keep the stronger
   invariant, deny LIVE before L6 now, and request a concrete owner ADR only after
   all independent engineering before owner-local live gates. Never silently weaken
   the financial trust boundary to obtain passing tests.
