# ADR-0005 — Math Mode Quantitative Authority

Status: Accepted

## Context

Math Mode was requested as a genuinely mathematical trading mode, not an LLM chart opinion.

## Decision

The authoritative live Math Mode signal/edge calculation comes from validated quantitative/statistical code/models with explicit cost/risk inputs.

LLMs may research, propose hypotheses, orchestrate experiments and explain outputs but cannot substitute free-form judgment for the authoritative live calculation.

## Consequences

Math Mode remains testable/reproducible and can operate safely when AI is unavailable if its certified deterministic components permit it.
